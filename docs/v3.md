## Executive Summary

v3 extends the unified parsing architecture to legacy Microsoft Office binary formats: Word 97–2003 (`.doc`) and PowerPoint 97–2003 (`.ppt`). 

Docling does not parse legacy binary formats natively. Instead of maintaining ad-hoc scrapers like `antiword` or losing slide structure, v3 introduces `LibreOfficeConverter`. It runs LibreOffice in headless batch mode inside an isolated temporary directory to convert `.doc` to `.docx` and `.ppt` to `.pptx`. The converted bytes are then forwarded directly to `DoclingParser`, producing a standard `DoclingDocument` for `HybridChunker`.

```
Incoming (.doc / .ppt)
        │
        ▼
   ParserRouter
        │
        ▼
LibreOfficeConverter (BaseParser)
        │
        ├─ 1. Write file bytes to isolated temporary directory
        ├─ 2. Execute headless soffice (--headless --convert-to docx/pptx)
        │     with isolated user profile (-env:UserInstallation)
        ├─ 3. Read converted (.docx / .pptx) bytes from temp dir
        │
        ▼
  DoclingParser (.docx / .pptx)
        │  (inherits v2/v2.1 fixes: contextualize, pseudo-headings, picture desc)
        ▼
  DoclingDocument
        │
        ▼
  HybridChunker ──> TextChunk[]
```

Legacy endpoints (`core/parser.py`) and existing v1/v2 parsers remain completely untouched.

## Phase 1: Binary Discovery & Headless Conversion Logic

### What is happening
Implement helper `find_libreoffice_binary()` and conversion mechanics in `parsers/libreoffice_converter.py`.
- **Binary lookup**: Checks `settings.libreoffice_binary`, system `PATH` (`libreoffice`, `soffice`), standard Windows installation folders (`C:\Program Files\LibreOffice\program\soffice.exe`), and standard Linux paths.
- **Process & Profile Isolation**: LibreOffice headless can suffer concurrency deadlocks if multiple worker processes share the default user profile. We pass `-env:UserInstallation=file:///<temp_dir>/lo_profile` so every conversion job runs with an isolated profile and clean lock state.
- **Timeout & Failure Handling**: Corrupt or password-protected legacy documents could cause headless processes to hang. Subprocess calls are guarded with a timeout (`subprocess.TimeoutExpired`) and capture standard error to raise `LibreOfficeConversionError`.

### Key Code Snippets
```python
# parsers/libreoffice_converter.py
def find_libreoffice_binary() -> str:
    # 1. Configured path or env override
    if settings.libreoffice_binary:
        which = shutil.which(settings.libreoffice_binary) or Path(settings.libreoffice_binary)
        if Path(which).is_file():
            return str(which)
    # 2. PATH resolution
    for name in ("libreoffice", "soffice"):
        which = shutil.which(name)
        if which:
            return which
    # 3. Common Windows locations
    for p in [r"C:\Program Files\LibreOffice\program\soffice.exe", r"C:\Program Files (x86)\LibreOffice\program\soffice.exe"]:
        if Path(p).is_file():
            return p
    raise LibreOfficeNotFoundError("LibreOffice binary not found on PATH or config.")
```

```python
# Inside LibreOfficeConverter.convert_to_openxml()
cmd = [
    binary,
    "--headless",
    "--invisible",
    "--nologo",
    "--nodefault",
    "--nofirststartwizard",
    f"-env:UserInstallation={(temp_path / 'profile').as_uri()}",
    "--convert-to", target_format,
    "--outdir", str(temp_path),
    str(input_file),
]
proc = subprocess.run(cmd, capture_output=True, text=True, timeout=self._timeout)
```

## Phase 2: `LibreOfficeConverter` Implementation (`BaseParser`)

### What is happening
Create `LibreOfficeConverter` inheriting from `BaseParser`.
- Implements `can_handle(ext)` for `.doc` and `.ppt`.
- Maps `.doc` ➔ `.docx` and `.ppt` ➔ `.pptx`.
- In `parse(file_bytes, filename, **kwargs)`:
  1. Writes bytes to temporary disk storage and converts via headless LibreOffice.
  2. Reads converted `.docx` or `.pptx` bytes into memory.
  3. Forwards converted bytes into an instance of `DoclingParser(BaseParser)`.
  4. Returns the resulting `DoclingDocument` containing full headings, tables, and slide structure.

### Key Code Snippets
```python
# parsers/libreoffice_converter.py
class LibreOfficeConverter(BaseParser):
    SUPPORTED_EXTENSIONS = frozenset({".doc", ".ppt"})
    TARGET_MAP = {".doc": "docx", ".ppt": "pptx"}

    def __init__(self, docling_parser: DoclingParser | None = None, timeout: int | None = None) -> None:
        self._docling_parser = docling_parser or DoclingParser()
        self._timeout = timeout or settings.libreoffice_timeout_seconds

    def can_handle(self, ext: str) -> bool:
        return ext.lower() in self.SUPPORTED_EXTENSIONS

    def parse(self, file_bytes: bytes, filename: str, **kwargs) -> DoclingDocument:
        converted_bytes, target_filename = self.convert_to_openxml(file_bytes, filename)
        return self._docling_parser.parse(converted_bytes, target_filename, **kwargs)
```

## Key Rules & Guardrails for Implementing Model

1. **Concise Comments Only:** Use single-line comments only when strictly needed to clarify a non-obvious line. Do not write multi-line commentary blocks or verbose docstring essays in the code.
2. **Subprocess Isolation:** Always pass `-env:UserInstallation=file:///<profile_dir>` to prevent profile lock conflicts during concurrent conversions.
3. **Subprocess Timeout:** Always specify a timeout on `subprocess.run` to prevent zombie processes on corrupt files.
4. **Preserve Legacy Paths:** Do not touch `core/parser.py` or existing endpoints. v3 is strictly internal until v4 switches the ingestion router.
